## 2023-10-29 - Three.js static mesh matrixAutoUpdate
**Learning:** In a voxel engine (or any Three.js scene) with thousands of static meshes, Three.js will by default recalculate the world matrix for every object on every frame (`scene.updateMatrixWorld()`). If not using `InstancedMesh`, this can cause massive CPU overhead and drop frame rates significantly. Setting `matrixAutoUpdate = false` and calling `updateMatrix()` once upon creation avoids this recalculation loop entirely.
**Action:** When adding static objects to a Three.js scene, always set `matrixAutoUpdate = false` and call `updateMatrix()` once, unless the object is going to move or rotate. For huge amounts of identical geometries, consider using `InstancedMesh` instead, but for distinct materials/geometries, disabling auto-update is essential.
